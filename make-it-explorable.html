Make it explorable

One line turns it interactive — hover any point to see which gene it is:

library(plotly)
ggplotly(volcano)

👉 Your turn

Add dashed threshold lines to the static volcano so the cutoffs are visible: vertical lines at log2FoldChange = −1 and 1, and a horizontal line at the p = 0.05 level. (Hint: geom_vline(), geom_hline(), linetype = "dashed".)

Solution 
volcano +
  geom_vline(xintercept = c(-1, 1), linetype = "dashed") +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed")
