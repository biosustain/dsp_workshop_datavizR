Data Visualization in R

Choose your setup

Pick whichever suits you — all three lead to the same exercises.

☁️ 1. In the cloud (nothing to install)

Run everything in your browser with GitHub Codespaces. Best if you don’t want to install anything.

💻 2. On your own computer

Prefer working locally? Install R and RStudio, then install the required packages below. You’ll keep everything you build after the workshop.

# List of required CRAN packages
packages <- c(
  "tidyverse",   # dplyr, ggplot2, tidyr, readr, tibble, ... (everything we use)
  "plotly",      # interactive plots
  "ggrepel",     # non-overlapping labels on the volcano
  "bookdown",    # to build this website locally
  "rmarkdown"
)

# Install missing packages
install_if_missing <- function(pkg) {
  if (!requireNamespace(pkg, quietly = TRUE)) {
    install.packages(pkg, repos = "https://cloud.r-project.org/")
  } else {
    message(pkg, " already installed.")
  }
}

# Run installation
invisible(lapply(packages, install_if_missing))

message("All requested R packages are installed and ready to use!")
