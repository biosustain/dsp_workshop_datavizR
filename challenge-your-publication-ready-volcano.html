8 Challenge: your publication-ready volcano

This is the hands-on hour. You’ve built every piece — now make a volcano plot you’d be proud to put in a paper. Use your AI assistant freely.

Your mission: start from de_plot and produce a polished volcano that:

  1. shows dashed threshold lines (fold change ±1, p = 0.05);
  2. labels the ~10 most significant genes (hint: the ggrepel package);
  3. has a clean theme, a clear title, and readable, colourblind-friendly colours;
  4. is one you can explain to a colleague in a sentence.

Everything you need is already loaded: de_plot, volcano, and the tidyverse.

📌 Remember the big idea: the plot is the answer to “which genes change between biofilm and planktonic?” — make that answer jump out.

🤖 Ask your AI (ideas): “How do I label only the top 10 genes on a ggplot volcano with ggrepel?” · “Suggest a colourblind-friendly palette for up/down/ns.” · “How do I make this figure look publication-ready?” — then run it, read it, and check it does what you expect.

One possible solution 
library(ggrepel)

top_genes <- de_plot %>%
  filter(status != "Not significant") %>%
  slice_max(-log10(padj), n = 10)

ggplot(de_plot, aes(x = log2FoldChange, y = -log10(padj))) +
  geom_point(aes(colour = status), alpha = 0.6) +
  geom_vline(xintercept = c(-1, 1), linetype = "dashed", colour = "grey50") +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed", colour = "grey50") +
  geom_text_repel(data = top_genes, aes(label = gene_id),
                  size = 3, max.overlaps = Inf) +
  scale_colour_manual(values = c("Up in biofilm"   = "#D55E00",
                                 "Down in biofilm" = "#0072B2",
                                 "Not significant" = "grey70")) +
  labs(title = "S. aureus: biofilm vs planktonic (24 h)",
       x = "log2 fold change", y = "-log10(adjusted p-value)", colour = NULL) +
  theme_minimal(base_size = 13)
