3 The grammar of graphics

Before we touch the real data, let’s learn the one idea that powers every plot in ggplot2: the grammar of graphics. Every plot is built from three pieces:

data → aesthetics (aes: which column goes on x, y, colour…) → geom (how to draw it)

We’ll learn it on a tiny built-in dataset, mpg (fuel economy of cars), then use it on our bacteria.

A plot grows by adding layers with +:

ggplot(mpg, aes(x = displ, y = hwy)) +   # data + aesthetics
  geom_point()                           # geom: draw points

Add a colour aesthetic and a second layer (a trend line):

ggplot(mpg, aes(x = displ, y = hwy, colour = class)) +
  geom_point() +
  geom_smooth() +
  labs(title = "Bigger engines use more fuel",
       x = "Engine size (L)", y = "Highway mpg")

That’s the whole idea. Everything today is just data → aes → geom + layers.

📌 Principle: pick the aesthetic for each variable (position, colour, shape…) and the geom for how to show it. Change those two and you change the plot.

👉 Your turn

Using mpg, make a scatter plot of cty (x) vs hwy (y), and colour the points by drv (drivetrain). Then give it proper axis labels.

Solution 
ggplot(mpg, aes(x = cty, y = hwy, colour = drv)) +
  geom_point() +
  labs(x = "City mpg", y = "Highway mpg", colour = "Drivetrain")
